# Skill Registry - La Vin Nails

## Compact Rules

### Backend Expert
- **MERN Stack**: Use Node.js, Express, MongoDB (Mongoose).
- **Architecture**: Modular controllers, models, middlewares.
- **Rules**: Always handle errors with `next()`, use `http-errors` for standardized responses.

### Frontend Expert
- **React Standards**: Use Container/Presentational pattern.
- **Pure JS**: NO TypeScript. Use JSDoc for types and documentation.
- **Custom Hooks**: Extract logic into hooks like `useBookings` or `usePushNotifications`.
- **API Calls**: Centralize in axios instances (e.g., `web/src/api/client.js`).

### PWA Expert
- **Service Worker**: Use Workbox for caching and routing.
- **Push Notifications**: Use Web Push API. Follow standard push and notificationclick event patterns.
- **iOS Compatibility**: Use `h-dvh` instead of `h-screen` or `100vh`. Ensure `font-size: 16px` min for inputs.

### UX/UI Design
- **Estética PREMIUM**: Use colors harmonious (HSL), smooth gradients, and micro-animations.
- **Typography**: Google Fonts (Inter, Roboto, or Outfit).
- **Mobile-First**: Design primarily for mobile (Safari iOS focus).
