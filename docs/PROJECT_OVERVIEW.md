# Visión General del Proyecto: La Vin Nails

Este proyecto es una plataforma web para un salón de belleza y uñas, permitiendo a los usuarios visualizar servicios, ver el portafolio de trabajos y solicitar citas.

## Objetivos
1.  **Transformación Digital**: Pasar de la gestión manual de servicios y citas a una plataforma centralizada.
2.  **Visibilidad**: Exponer el portafolio de alta calidad para atraer nuevas clientas.
3.  **Facilidad de Gestión**: Permitir a la administradora cambiar el catálogo a través de Notion.

## Repositorio y Entorno
- **Localización**: `d:\Proyectos web\web-la-vin\web-la-vin-nails-react`
- **Carpetas**:
  - `api/`: El backend en Node.js/Express.
  - `web/`: El frontend en React (Vite/React-Scripts).
- **Despliegue**: Se utiliza Fly.io para el hosting tanto de la API como del frontend.
